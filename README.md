# OneHub AI
Starter Android app that launches Zomato, Swiggy and Blinkit, with a simple smart command box.

## Build APK online with GitHub
1. Create a new GitHub repository.
2. Upload all project files, including the `.github` folder.
3. Open the **Actions** tab.
4. Open **Build Android APK** and run the workflow (or push to main).
5. Open the finished workflow and download the **OneHubAI-debug-apk** artifact.

## Notes
- If a supported app is installed, OneHub AI opens it; otherwise it opens the service website.
- Real AI chat should use a secure backend. Do not put a private AI API key directly inside an Android APK.
